# Continuous nursery

This is a small stable workspace for supervised pulse blocks.

- `objects/blue-square.txt` describes a familiar matching object.
- `objects/red-circle.txt` describes a deliberate mismatch.
- `scripts/lamp_status.py` safely reports the room state.

New notices may make one of these items relevant. Inspect or run only what is
useful for the current notice. Repeating an unchanged observation adds no new
evidence.
